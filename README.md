## 📖 About

**BASICS of Unity** is a hands-on playground repo for learning core Unity game‑dev concepts — player movement, physics, input handling, and simple game loops — through a set of small, focused scenes rather than one big project.

> 🎯 Built for learning. Broken things, commented‑out experiments, and messy scripts are part of the process — that's the point!

<br/>

## 🎮 Scenes Included

<div align="center">

| Scene | Concept Practiced | Status |
|:------|:------------------|:------:|
| 🏃 `Endless-Runner` | Continuous forward movement & obstacles | ✅ |
| 👻 `Hide-Show-Player` | Object visibility / activation toggling | ✅ |
| 🏎️ `RacingGame` | Turning, acceleration & braking controls | ✅ |
| 🌊 `Smooth-Movement` | Lerp / interpolation-based smooth movement | ✅ |

</div>

<br/>

## ✨ Features

- 🚗 **Vehicle-style controls** — `turnLeft()`, `turnRight()`, `Accelerate()`, `Break()`
- 🏃 **Auto-forward movement** using `transform.Translate` with `Time.deltaTime`
- ⚙️ **Rigidbody-based physics setup** ready for jump/force mechanics
- 🧩 **Modular scripts** — each scene isolates a single mechanic to learn
- 🪶 **Lightweight project** — minimal assets, fast to open and experiment with

## 🚀 Getting Started

<details open>
<summary><b>Click to expand setup instructions</b></summary>

<br/>

1. **Clone the repository**
   ```bash
   git clone https://github.com/Bhuvan211/BASICS-Of-Unity.git
   ```

2. **Open with Unity Hub**
   - Launch **Unity Hub**
   - Click **Add** → select the cloned folder
   - Use Editor version **`2023.2.22f1`** (or later) for best compatibility

3. **Open a scene**
   - Navigate to `Assets/Scenes/`
   - Double‑click any `.unity` scene (e.g. `RacingGame.unity`)

4. **Press ▶️ Play** and start experimenting!

</details>
